## 1. The Linux story

During the 80s and 90s, Microsoft had a tight grip on the computer software market. In 1991, 90% of computers ran on Microsoft DOS or the then-new Microsoft Windows. DOS and Windows are what they call "closed source", where no one outside of Microsoft truly knows how the code behind it works.

That needed to change, and on September 17, 1991, Linus Torvalds released the first version of Linux. Linux is not only open source, where everyone can see how it works, and with enough technical knowledge, add code to help Linux move forward.

That "closed and open source" is what brings the difference in philosophy between Windows and Linux. Because Microsoft has complete control over Windows, they take actions that are often anti-consumer in order to make more profit. This is not possible with Linux because it is from the users, for the users. And so there is no large corporation behind it.

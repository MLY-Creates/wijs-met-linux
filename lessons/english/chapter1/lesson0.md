# Understand Linux

Linux is, just like Windows, an operating system. An operating system is a program that ensures that your computer can function properly, and that all processes run. On computers without an operating system, you can't do anything. There are many similarities between Linux and Windows. But there are also many differences.

Your computer is about to get a new life. But before you can use Linux, it's helpful to understand it first. That's what this chapter is about.

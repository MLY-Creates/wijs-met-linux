## 2. Why Linux on your computer?

Because Linux is open and not dependent on a large corporation, it is made and maintained by users themselves. This brings several advantages, such as:

1. linux is a lot easier to run on an older computer without it becoming slow. Linux also does not send data to a large company, so less happens in the background, and your computer can run faster.
2. Because Linux does not send data to large companies by itself, you are safer in the event of a data breach.
3. Linux is veiliger, doordat het open is worden veiligheidsfouten sneller gevonden. Ook worden er minder virussen voor gemaakt.
4. Linux bevat geen abbenomenten en advertenties, ook dat komt omdat er geen groot bedrijf met winstoogmerk achter zit.

# Help with Wijs in Linux!

Are you multilingual and think you can bring Wijs in Linux to more users? Then you can help us.

Currently, this website is only available in Dutch and English. Would you like to translate Wijs in Linux into another language? Please read the instructions below:

> **Note**
>
> To help with the translations, at least a basic level of computer skills is desirable.

1. Download the ZIP files of the languages that still need to be translated from the list below.
2. Unpack the files. You can do this from your file manager.
3. Translate the text in the correct files. Do this in files ending in "md". Avoid translating code.
4. Send the translations using the list below by clicking the corresponding "Mail your translation" button.
5. Once the translations are approved, you will be added to the list of translators. Your impact really makes a difference!
